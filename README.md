# Auto Ping Pong

[SPP — Snap Ping Pong](https://hooni9807.github.io/spp/)의 탁구 동호회 캐릭터들로 만든 오토배틀러 게임입니다. 슈퍼오토펫의 규칙으로 팀을 짜고, 롤토체스처럼 육각 보드 위에서 캐릭터들이 탁구채를 들고 자동으로 싸웁니다.

**플레이:** https://hooni9807.github.io/auto-ping-pong/

## 게임 방법

1. Google로 로그인하면 로비로 넘어갑니다. 로그인 전 첫 화면에서는 실제 경기를 미리 볼 수 있습니다. 로비에서 **AI 대전**을 누르고 난이도를 고르면 바로 시작합니다. 하던 게임이 있으면 **이어하기**가 함께 나옵니다.
2. 매 턴 골드 10개를 받습니다. 상점 카드를 보드 칸으로 끌어다 놓거나, 카드를 누른 뒤 칸을 눌러 배치합니다. 카드 오른쪽 위 숫자는 코스트(티어)입니다.
3. **전투 시작**을 누르면 상대 팀과 자동으로 싸웁니다. 휴대폰에서는 전투 화면이 화면 전체를 채웁니다. 맨 앞 캐릭터끼리 동시에 공격하고, 쓰러지면 뒤에 있던 캐릭터가 앞으로 나옵니다.
4. 이기면 트로피 +1, 지면 체력 -1입니다. 트로피 10개를 모으면 우승, 체력 5가 다 떨어지면 게임 오버입니다.

| 항목 | 규칙 |
|---|---|
| 골드 | 매 턴 10 (다음 턴으로 넘어가지 않음) |
| 캐릭터 · 장비 구매 | 3골드 |
| 새로고침(리롤) | 1골드 |
| 판매 | 레벨만큼 골드를 돌려받음 |
| 팀 | 최대 5명. 보드는 팀마다 2줄 × 5칸, 맨 앞 칸이 먼저 싸움 |
| 티어 해금 | 2턴마다 한 티어씩, 11턴에 6티어까지 |
| 합성 | 같은 캐릭터를 겹치면 경험치 +1, 3마리 ★★, 6마리 ★★★ |
| 레벨업 보너스 | 상점에 한 단계 위 티어 캐릭터가 추가됨 |
| 얼리기 | 상점 칸을 얼려 두면 다음 턴에도 남음 |
| 패배 시 체력 | 질 때마다 -1 |

### AI 난이도

| 난이도 | AI 상대 |
|---|---|
| 이지 | 매 턴 골드 -3, 합성을 자주 놓치고 아무 캐릭터나 삼 |
| 하드 | 나와 같은 규칙으로 꼼꼼하게 팀을 짬 |
| 익스트림 | 매 턴 골드 +2, 턴이 끝날 때 랜덤 캐릭터 2명 +1/+1 |
| 울트라 | 매 턴 골드 +4, 턴이 끝날 때 모든 캐릭터 +1/+1 |

같은 실력의 AI로 시뮬레이션하면 한 판 승률이 이지 약 80%, 하드 약 47%, 익스트림 약 13%, 울트라 약 5%입니다.

### PVP (친구와 실시간 대결)

로비의 **PVP** 버튼을 누르면 PVP 창이 열립니다.

- **방 만들기**: 5자리 방 코드가 나옵니다. 친구에게 코드를 알려 주세요.
- **방 참가**: 친구가 알려 준 코드를 넣고 참가를 누르면 두 사람 모두 바로 게임이 시작됩니다.
- 두 사람이 같은 라운드에 각자 상점에서 팀을 짭니다(라운드마다 75초, 시간이 다 되면 자동 제출). 둘 다 준비되면 **같은 전투가 두 화면에서 동시에** 재생됩니다. 화면 오른쪽 위에 상대의 체력과 "팀 정하는 중 / 준비 완료"가 실시간으로 보입니다.
- 트로피 10개를 먼저 모으거나 상대 체력을 0으로 만들면 승리합니다. 도중에 나가면 패배로 기록되고, 상대가 나가면 기권승입니다.
- 동기화: Firestore 방 문서(`autopets_rooms/{코드}`) 하나에 두 사람이 라운드마다 팀을 올리고 실시간으로 구독합니다. 두 기기가 같은 씨앗(seed)의 난수로 같은 전투를 계산하므로 결과가 똑같이 나옵니다.

### PVP 랭킹 (점수제)

PVP는 1000점에서 시작하고, 한 판마다 상대 점수에 따라 점수가 오르내립니다(Elo, 한 판 최대 ±40). 점수에 따라 부수가 정해집니다(SPP 랭크전과 같은 구간).

| 점수 | 부수 |
|---|---|
| 1000 미만 | 초심부 |
| 1000 | 7부 |
| 1100 | 6부 |
| 1200 | 5부 |
| 1300 | 4부 |
| 1400 | 3부 |
| 1600 | 2부 |
| 1800 | 1부 |
| 2000 | 선수부 |

로비 랭킹판의 **PVP 랭킹** 탭에서 전체 순위(상위 50명)를 볼 수 있습니다.

### 설정

로비와 게임 화면 오른쪽 위 톱니바퀴 버튼에서 바꿀 수 있고, 이 기기에 저장됩니다.

- 배경음악 켜기/끄기와 크기 · 효과음 켜기/끄기와 크기
- 화려한 이펙트(아우라 · 입자 · 번쩍임 · 화면 확대) 켜기/끄기
- 화면 흔들림 · 피해 숫자 켜기/끄기
- 기본 전투 속도(1배속 · 2배속)

배경음악은 음원 파일 없이 브라우저에서 직접 만듭니다(112BPM 가단조 판타지 비트에 탁구공 튀는 소리). 효과음도 타격 · 필살기 · 구매 · 승리 · 패배마다 다르게 납니다.

### 랭킹

로비의 AI 대전 버튼 아래에 랭킹판이 있습니다. 게임이 끝날 때마다(트로피 10개 우승 또는 체력 0) 닉네임 · 난이도 · 날짜와 시간 · 승리/패배(트로피 수)가 한 줄씩 기록되고, 최근 기록 30개를 난이도별로 걸러 볼 수 있습니다. 내 기록은 금빛으로 표시됩니다. 기록은 Firestore `autopets_rank`에 쌓이며 고치거나 지울 수 없습니다.

### 상점 표시

- 2성으로 레벨업하면 상점에 추가되는 보너스 캐릭터는 보라·하늘색으로 맥박치는 테두리와 "레벨업 보너스" 띠로 구분됩니다.
- 상점 줄은 휴대폰에서는 손가락으로 옆으로 밀고, PC에서는 마우스로 옆으로 끌거나 휠을 굴려 넘깁니다. 위로 끌어올리면 구매(드래그 앤 드롭)입니다.

## 시너지

롤토체스처럼 캐릭터마다 시너지가 1~2개 있습니다. 보드에 올린 **서로 다른** 캐릭터 수로 세고, 정해진 인원에 닿으면 효과가 켜집니다. 보드 왼쪽 위에 내 팀, 오른쪽에 상대 팀의 시너지가 `공격수 3/4`처럼 현재 인원 / 다음 단계 인원으로 표시되고, 켜진 시너지는 색이 들어옵니다. 상점 카드에는 그 캐릭터의 시너지가 짧은 이름(공격 · 수비 · 아재 · 테크 · 이중 · 보스 · 역전)으로 붙고, 이미 내 보드에 있는 시너지는 색이 채워져 보입니다. 보드에 이미 있는 캐릭터가 상점에 나오면 카드 테두리에 빛이 돌며 반짝여서 합성할 카드를 바로 찾을 수 있습니다.

| 시너지 | 단계 | 효과 | 캐릭터 |
|---|---|---|---|
| 공격수 | 2 / 4 | 아군 전체 공격 +2 / +5 | 휴고범, 일병3호봉, 퍼시벌, 리신범, 올인 도박사, 민희쌤 |
| 수비수 | 2 / 4 | 아군 전체 받는 피해 -1 / -2 (최소 1) | 빽종령, 송스타, 무한 리턴 봇, 금호관장, 카사노바 윤 |
| 동호회 아재 | 2 / 4 | 아군 전체 체력 +3 / +7 | 아재범, 빽종령, 만취범, 금호관장, 허허 목사 |
| 테크니션 | 2 / 3 | 필살기 게이지 40 / 80으로 시작 | 날먹세, 아담 성, 매혹범, 갓융자, 맹타치 |
| 이중인격 | 2 / 3 | 아군이 쓰러질 때마다 이중인격 아군 공격 +2 / +4 | 졸린 지킬, 하이드, 지킬앤 하이범 |
| 보스 | 2 / 3 | 전투 시작: 모든 적에게 2 / 4 피해 | 매혹범, 갓융자, 탁구 마왕, 민희쌤 |
| 역전 | 2 / 3 | 역전 아군이 쓰러지면 남은 아군 +2/+2 / +4/+4 | 만취범, 김치성, 올인 도박사 |

로비의 **시너지 도감** 버튼을 누르면 시너지마다 단계별 효과와 소속 캐릭터(얼굴 · 코스트)를 한눈에 볼 수 있습니다.

보드 위에서 내 캐릭터는 몸통이 파란 테두리, 상대 캐릭터는 빨간 테두리로 구분합니다. 탁구채 러버 색은 캐릭터마다 빨강 · 검정 · 분홍 · 파랑 · 초록 중 하나입니다.

| 플릭 | 랜덤 적에게 공격력 절반 피해 ×3 |

### 장비

탁구 용품을 캐릭터에게 장착합니다. 모두 3골드이고, 카드의 숫자는 몇 코스트(티어)짜리인지입니다.

| 장비 | 코스트 | 효과 |
|---|---|---|
| 머리띠 | 1 | +1/+1 |
| 꿀벌공 | 1 | 쓰러지면 1/1 꿀벌 소환 |
| 물병 | 2 | +1/+1, 경험치 +1 |
| 새 러버 | 2 | 공격 피해 +3 |
| 무릎보호대 | 3 | 받는 피해 -2 (최소 1) |
| 유니폼 하의 | 3 | 랜덤 아군 2명 +1/+1 |
| 유니폼 상의 | 4 | 랜덤 아군 3명 +1/+1 |
| 발목보호대 | 5 | 받는 피해 -20 (1회) |
| 탁구화 | 6 | 랜덤 아군 2명 +2/+2 |
| 손목보호대 | 6 | 다음 공격 피해 +20 (1회) |

## 전투 연출

캐릭터마다 때리는 방식, 움직이는 방식, 자세, 맞았을 때 이펙트가 다릅니다. 리신범은 불꽃 날아차기, 맹타치는 순간이동 베기, 탁구 마왕은 점프 내려찍기, 무한 리턴 봇은 레이저, 날먹세는 서브, 매혹범은 하트, 갓융자는 카드, 허허 목사는 하늘의 빛기둥으로 공격합니다. 모든 공격은 기를 모으고 → 때리고 → 돌아오는 순서로 움직입니다.

- **★★**: 몸 주위 아우라, 발밑 회전 고리, 피어오르는 빛 입자, 기 모을 때 빨려 드는 입자, 공격 잔상, 번쩍임. 쓰러뜨린 상대는 산산조각으로 흩어집니다.
- **★★★**: 초사이언처럼 금빛 불꽃 아우라와 금빛 머리, 번개. 기를 모으면 화면이 어두워지고, 화면 밖(카메라 쪽)으로 솟구쳤다가 내리꽂힙니다. 맞는 순간 화면이 번쩍이고 흔들리며, 쓰러뜨린 상대는 반으로 쪼개집니다.

기기에서 '동작 줄이기'를 켜면 화면 흔들림과 확대가 꺼집니다.

## 저장

Google로 로그인하면 Firestore의 `autopets/{uid}` 문서 하나에 저장되고, 끝난 판의 결과는 랭킹(`autopets_rank`)에 남습니다.

- 진행 중인 게임: 턴이 시작될 때마다 저장. 다른 기기에서 로그인해도 이어서 할 수 있습니다.
- 기록: 완주한 판 수, 우승 횟수, 최고 트로피 수.

보안 규칙은 [`firestore.rules`](firestore.rules)에 있습니다. 구글로 로그인한 본인만 자기 문서를 읽고 쓸 수 있습니다.

## 구조

빌드 없는 정적 사이트입니다.

```
index.html        게임 전체 (규칙 엔진 · 봇 · 육각 보드 캔버스 렌더러 · 로그인/저장)
faces/            캐릭터 얼굴 이미지 (SPP에서 가져와 320px로 줄임)
firestore.rules   Firestore 보안 규칙
```

- 상대 팀은 플레이어와 같은 상점 규칙으로 팀을 짜는 봇입니다.
- 전투 엔진은 결과를 프레임 목록으로 미리 계산하고, 캔버스 렌더러가 그 프레임을 애니메이션으로 재생합니다.

### 로컬에서 실행

```bash
python3 -m http.server 8000
```

http://localhost:8000 을 엽니다. `localhost`는 Firebase 승인 도메인에 기본으로 들어 있어 로그인도 됩니다.

### Firebase

- 프로젝트: `auto-ping-pong-b04bd` (Spark 무료 요금제)
- 로그인: Google
- 승인된 도메인: `hooni9807.github.io`
- Firestore: Standard, 서울(`asia-northeast3`). 컬렉션: `autopets`(진행 저장) · `autopets_rank`(AI 기록) · `autopets_rooms`(PVP 방) · `autopets_pvp`(PVP 점수)
- 규칙을 바꾸면 `firestore.rules`를 Firebase 콘솔의 Firestore 규칙 탭에 붙여 넣고 게시합니다.
