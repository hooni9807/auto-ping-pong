# Auto Ping Pong

[SPP — Snap Ping Pong](https://hooni9807.github.io/spp/)의 탁구 동호회 캐릭터들로 만든 오토배틀러 게임입니다. 슈퍼오토펫의 규칙으로 팀을 짜고, 롤토체스처럼 육각 보드 위에서 캐릭터들이 탁구채를 들고 자동으로 싸웁니다.

**플레이:** https://hooni9807.github.io/auto-ping-pong/

## 게임 방법

1. Google로 로그인하면 메인 화면으로 넘어갑니다. 로그인 전 첫 화면에서는 실제 경기를 미리 볼 수 있습니다.
2. 매 턴 골드 10개를 받습니다. 아래 상점에서 캐릭터를 고른 뒤 보드의 빈 칸을 눌러 배치합니다.
3. **전투 ▶** 를 누르면 상대 팀과 자동으로 싸웁니다. 맨 앞 캐릭터끼리 동시에 공격하고, 쓰러지면 뒤에 있던 캐릭터가 앞으로 나옵니다.
4. 이기면 트로피 +1, 지면 체력이 깎입니다. 트로피 10개를 모으면 우승, 체력 5가 다 떨어지면 게임 오버입니다.

| 항목 | 규칙 |
|---|---|
| 골드 | 매 턴 10 (다음 턴으로 넘어가지 않음) |
| 캐릭터 · 음식 구매 | 3골드 |
| 새로고침(리롤) | 1골드 |
| 판매 | 레벨만큼 골드를 돌려받음 |
| 팀 | 최대 5명. 보드는 팀마다 2줄 × 5칸, 맨 앞 칸이 먼저 싸움 |
| 티어 해금 | 2턴마다 한 티어씩, 11턴에 6티어까지 |
| 합성 | 같은 캐릭터를 겹치면 경험치 +1, 3마리 ★★, 6마리 ★★★ |
| 레벨업 보너스 | 상점에 한 단계 위 티어 캐릭터가 추가됨 |
| 얼리기 | 상점 칸을 얼려 두면 다음 턴에도 남음 |
| 패배 시 체력 | 1~2턴 -1, 3~4턴 -2, 5턴부터 -3 |

## 시너지

롤토체스처럼 캐릭터마다 시너지가 1~2개 있습니다. 보드에 올린 **서로 다른** 캐릭터 수로 세고, 정해진 인원에 닿으면 효과가 켜집니다. 보드 왼쪽 위에 `공격수 3/4`처럼 현재 인원 / 다음 단계 인원이 표시되고, 켜진 시너지는 색이 들어옵니다. 상점 카드 오른쪽 위의 색 점이 그 캐릭터의 시너지입니다.

| 시너지 | 단계 | 효과 | 캐릭터 |
|---|---|---|---|
| 공격수 | 2 / 4 | 아군 전체 공격 +2 / +5 | 휴고범, 일병3호봉, 퍼시벌, 리신범, 올인 도박사, 민희쌤 |
| 수비수 | 2 / 4 | 아군 전체 받는 피해 -1 / -2 (최소 1) | 빽종령, 송스타, 무한 리턴 봇, 금호관장, 카사노바 윤 |
| 동호회 아재 | 2 / 4 | 아군 전체 체력 +3 / +7 | 아재범, 빽종령, 만취범, 금호관장, 허허 목사 |
| 테크니션 | 2 / 3 | 필살기 게이지 40 / 80으로 시작 | 날먹세, 아담 성, 매혹범, 갓융자, 맹타치 |
| 이중인격 | 2 / 3 | 아군이 쓰러질 때마다 이중인격 아군 공격 +2 / +4 | 졸린 지킬, 하이드, 지킬앤 하이범 |
| 보스 | 2 / 3 | 전투 시작: 모든 적에게 2 / 4 피해 | 매혹범, 갓융자, 탁구 마왕, 민희쌤 |
| 역전 | 2 / 3 | 역전 아군이 쓰러지면 남은 아군 +2/+2 / +4/+4 | 만취범, 김치성, 올인 도박사 |

보드 위에서 내 캐릭터는 파란 테두리, 상대 캐릭터는 빨간 테두리로 구분합니다.

## 필살기

모든 캐릭터는 체력바 아래에 필살기 게이지가 있습니다. 기본 공격을 하면 +35, 맞고 살아남으면 +10이 차고, 100이 되면 [SPP](https://hooni9807.github.io/spp/)의 필살기를 시전합니다. 시전하면 게이지는 0으로 돌아갑니다.

| 계열 | 효과 |
|---|---|
| 루프 | 맨 앞 적에게 공격력 ×2 피해 |
| 번개 | 맨 앞 적에게 공격력 ×1.5, 그 뒤 적에게 절반 피해 |
| 낙뢰 | 모든 적에게 공격력 절반 피해 |
| 커브 | 맨 뒤 적에게 공격력 ×1.5 피해 |
| 환영 | 맨 앞 적의 공격력을 절반으로 낮추고 공격력 절반 피해 |
| 커트 | 맨 앞 적에게 공격력만큼 피해, 자신은 멜론 획득 |
| 플릭 | 랜덤 적에게 공격력 절반 피해 ×3 |

## 전투 연출

캐릭터마다 때리는 방식, 움직이는 방식, 자세, 맞았을 때 이펙트가 다릅니다. 리신범은 불꽃 날아차기, 맹타치는 순간이동 베기, 탁구 마왕은 점프 내려찍기, 무한 리턴 봇은 레이저, 날먹세는 서브, 매혹범은 하트, 갓융자는 카드, 허허 목사는 하늘의 빛기둥으로 공격합니다. 모든 공격은 기를 모으고 → 때리고 → 돌아오는 순서로 움직입니다.

- **★★**: 몸 주위 아우라, 발밑 회전 고리, 피어오르는 빛 입자, 기 모을 때 빨려 드는 입자, 공격 잔상, 번쩍임. 쓰러뜨린 상대는 산산조각으로 흩어집니다.
- **★★★**: 초사이언처럼 금빛 불꽃 아우라와 금빛 머리, 번개. 기를 모으면 화면이 어두워지고, 화면 밖(카메라 쪽)으로 솟구쳤다가 내리꽂힙니다. 맞는 순간 화면이 번쩍이고 흔들리며, 쓰러뜨린 상대는 반으로 쪼개집니다.

기기에서 '동작 줄이기'를 켜면 화면 흔들림과 확대가 꺼집니다.

## 저장

Google로 로그인하면 Firestore의 `autopets/{uid}` 문서 하나에 저장됩니다.

- 진행 중인 게임: 턴이 시작될 때마다 저장. 다른 기기에서 로그인해도 이어서 할 수 있습니다.
- 기록: 완주한 판 수, 우승 횟수, 최고 트로피 수.

보안 규칙은 [`firestore.rules`](firestore.rules)에 있습니다. 구글로 로그인한 본인만 자기 문서를 읽고 쓸 수 있습니다.

## 구조

빌드 없는 정적 사이트입니다.

```
index.html        게임 전체 (규칙 엔진 · 봇 · 육각 보드 캔버스 렌더러 · 로그인/저장)
faces/            캐릭터 얼굴 이미지 (SPP에서 가져와 320px로 줄임)
firestore.rules   Firestore 보안 규칙
```

- 상대 팀은 플레이어와 같은 상점 규칙으로 팀을 짜는 봇입니다.
- 전투 엔진은 결과를 프레임 목록으로 미리 계산하고, 캔버스 렌더러가 그 프레임을 애니메이션으로 재생합니다.

### 로컬에서 실행

```bash
python3 -m http.server 8000
```

http://localhost:8000 을 엽니다. `localhost`는 Firebase 승인 도메인에 기본으로 들어 있어 로그인도 됩니다.

### Firebase

- 프로젝트: `auto-ping-pong-b04bd` (Spark 무료 요금제)
- 로그인: Google
- 승인된 도메인: `hooni9807.github.io`
- Firestore: Standard, 서울(`asia-northeast3`)
- 규칙을 바꾸면 `firestore.rules`를 Firebase 콘솔의 Firestore 규칙 탭에 붙여 넣고 게시합니다.
